## Что это было

Элемент 28 заказа 124173_test — круг R 4.9. С умолчаниями там всё
чисто, поэтому в прошлый раз я ничего и не нашёл. Воспроизводится при
**малом угле захода**: при 10° длина прямой = боковой зазор / sin(10°),
лид почти ложится на контур и идёт **вдоль собственного лезвия**.

Перебор по пятке, смещению, длине и углу дал **68 сочетаний**, где заход
шёл через лезвие. Худшее — зазор 0.000 при нужных 0.850, то есть фреза
шла ровно по кромке.

### Почему проверка молчала

Для ЧУЖИХ ножей она давно меряет путь фрезы. А для СВОЕГО контура:

* мерила **осевую**, а не путь фрезы;
* освобождала зону «рядом со стыком» размером **0.8 габарита лида**.

У пологого захода лид длинный — зона выходила в несколько миллиметров, и
весь опасный участок оказывался внутри неё. Проверка смотрела мимо.

### Что сделано

Путь фрезы меряется до **точной геометрии** своего контура: дуги
аналитически, без ломаной. Ломаная тут не годится — с хордой 0.5 мм на
скруглении R 0.3 она врёт на 130 мкм, и порог «не ближе радиуса
инструмента» по ней не поставить: либо ложные срабатывания на вогнутых
участках, либо пропуск настоящих. Освобождается только окрестность
стыка — полрадиуса инструмента, а не размер лида.

```
Knife_28, перебор пятка × смещение × длина × угол:
    было   68 сочетаний с заходом через лезвие (худшее врезание 850 мкм)
    стало   0
```

## Тесты

Быстрые модули: **183 + 23 = 206 ok, 0 fail**.
Модуль машинируемости: прогоняется (результат в журнале сборки).

Два новых:

- `test_shallow_angle_lead_never_crosses_the_blade` — тот самый
  Knife_28 заказа 124173, 72 сочетания настроек. На коде v1.7.62
  падает: «2 захода через лезвие без пометки, худшее врезание 649 мкм».
  Заметьте, падает не только на 10°, но и на 45° со смещением +5 — то
  есть дыра была шире, чем ваш случай.
- `test_shallow_lead_does_not_run_along_its_own_blade` — то же на
  идеальном круге, без заказа.

Второй тест формулирует требование аккуратно: на идеальном круге сдвиг
старта не меняет ничего (вращательная симметрия), а угол подбор умеет
только ПОНИЖАТЬ — значит при 10° чистого решения может не быть вовсе.
Требование тогда не «всегда чисто», а «никогда молча»: такой лид обязан
быть помечен коллизией и подсвечен красным.

## В очереди

1. Подбор умеет понижать угол захода, но не повышать — на круге при
   пологом угле это не оставляет ему ходов.
2. Десять лидов основного прохода задевают лезвие на 1…16 мкм через
   цепочку вьювер→пост (из v1.7.62).
3. Один лид доработки задевает лезвие на 117 мкм, и проверка его не
   видит (из v1.7.61; было три — точный замер своего контура убрал
   два).
4. Что делать в щели, куда лид не помещается.
5. Прямые и незамкнутые контуры.
