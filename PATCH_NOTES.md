## Расхождение API с окном

Автоподбор угла и длины внутреннего лида (v1.7.69–1.7.71) включало
только главное окно — оно помечает, какие поля вы трогали. Через API
(`CamSession` без окна) этой отметки не было. Поэтому в режиме «Авто»
маленький кружок получал 45° / 1.0 из параметров, а не свои 90° / 0.8,
как в окне.

Теперь, если отметки нет, считается, что поля не трогали: угол и длина
подбираются по ножу так же, как в окне.

## Новое в API: режим заходов

```python
s = CamSession()
s.load_ai(path)
s.create_blade_operations()
s.set_lead_mode(0)        # «Авто» — правила подбора работают (по умолчанию)
s.set_lead_mode(1)        # «Все элементы» — заход строго по cutting_params
s.set_lead_mode(0, auto_angle=False, auto_length=False)
                          # «Авто», но угол/длина внутреннего лида — из
                          # cutting_params на все ножи (как тронутые поля)
```

Без вызова `set_lead_mode` работает «Авто» — как раньше.

## В очереди

1. Подбор умеет понижать угол захода, но не повышать.
2. Десять лидов основного прохода задевают лезвие на 1…17 мкм через
   цепочку вьювер→пост.
3. Лиды доработки задевают лезвие до 123 мкм, и проверка их не видит.
4. Проход без лида — фреза опускается на месте.
5. Что должен означать множитель радиуса лида.
6. Прямые и незамкнутые контуры.
